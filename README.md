## Overview

**PZ Build 42 Mod Manager** is a modern desktop application designed exclusively for **Project Zomboid Build 42**.

Manage Steam Workshop and local mods with an intuitive interface. Create multiple mod profiles, detect conflicts, resolve dependencies, update Workshop content, and organize your Build 42 experience with a single application.


## Features

- 📦 Mod library for Project Zomboid Build 42
- ☁ Steam Workshop integration
- 🔄 Automatic Workshop updates
- 🧩 Local mod management
- 🔗 Dependency detection
- ⚠ Conflict detection
- 📁 Multiple mod profiles
- ⭐ Favorites
- 💾 Backup & Restore
- 🔍 Fast search and filtering
- 📊 Mod statistics
- 🌙 Dark & Light themes
